# C Programming Fundamentals

My C programming coursework, following [CodeWithHarry's](https://www.youtube.com/@CodeWithHarry) YouTube course alongside a university C programming requirement.

## What's in here

- **Chapter 0** — Program structure, `Hello World`
- **Chapter 1** — Variables, naming rules, data types, `sizeof`, comments, user input (`scanf`), escape sequences
  - `Practice Set/` — the course's official hands-on problems (rectangle area, circle/cylinder, temperature conversion, simple interest)
  - `Extra Practice Programs/` — additional self-written exercises reinforcing each concept (swapping, division precision, formatted output, and more)

Every file is written and debugged by hand, with inline comments explaining the reasoning — including a few deliberately-kept "before" versions of bugs I hit and fixed (integer vs. float division, comma-operator misuse, format specifier mismatches), as a reference for what tripped me up and why.

## Toolchain

GCC (MinGW), compiled and tested on Windows.
